# Flight_Muscle_Atlas
The IFM Gene Network Atlas is an interactive web application for exploring gene networks associated with aging in Drosophila indirect flight muscle. It brings together results from three complementary approaches: graph neural networks (GNN), high dimensional weighted gene coexpression network analysis (hdWGCNA), and SCENIC regulatory network analysis. The atlas enables researchers to examine how gene relationships and expression patterns differ across D0, D25, and D50.
The gene workspace supports simultaneous exploration of up to three genes or candidate transcriptional regulators. Search suggestions distinguish genes from available regulons, while the default view centers on fln. Surrounding genes reveal coexpression or inferred regulatory connections, with up to thirty neighbors displayed per center. Network proximity reflects relationship strength, and directed red arrows highlight SCENIC regulator to target connections.
Users can independently display or hide hdWGCNA coexpression, positive and negative GNN correlations, SCENIC arrows, and regulon markers. These controls reduce visual overlap when several methods support the same neighborhood. Zooming, panning, fitting the network to the viewport, and adjustable labels help users inspect crowded networks and read gene names.
A broader overview organizes multiple genes into five hdWGCNA modules or six GNN programs, with colors and cluster arrangements adapting to the selected model. Additional views summarize individual gene neighborhoods, GNN dynamics, regulon activity, module hubs, functional annotations, and methodological information.
Age comparisons include D25 versus D0, D50 versus D25, and D50 versus D0. Selected gene pairs can be examined using a complete lookup of 2,847,691 pairwise correlations among 2,387 analysis genes. This preserves access to relationships outside the retained GNN graphs and coherent temporal patterns, supporting exploration of strengthening, weakening, and nonmonotonic changes. Hover explanations introduce unfamiliar terminology and clarify the meaning of different network scores.
Designed for GitHub Pages, the atlas runs in a web browser without visitor registration or an application server. Its integrated visualizations support hypothesis generation and candidate prioritization. However, coexpression and inferred regulation represent associations, while graph appearance or disappearance reflects analysis thresholds. With one source sample per age, temporal patterns remain descriptive and require independent biological validation. Publishing the atlas makes its bundled derived research results publicly accessible.
