IFM Gene Network Atlas — GitHub Pages upload package

1. Unzip this archive.
2. Create a GitHub repository and upload the CONTENTS of this folder.
3. Confirm docs/index.html appears directly under your repository.
4. Settings > Pages > Deploy from a branch > main > /docs > Save.
5. Open the website address GitHub shows after deployment completes.

Read README.md for step-by-step instructions and troubleshooting.
Read DATA_PUBLICATION.md: the included derived research data will be public.
The website is prebuilt. Visitors need no login or Node.js.
Do not upload the ZIP itself as the website.
